# Todo List App

A simple and stylish Todo List application built with **React** and **Tailwind CSS**.  

## ✨ Features

- Add, edit, and delete tasks  
- Mark tasks as completed  
- Responsive and clean UI with Tailwind styling  
- Persistent state (if using local storage or similar)  

## 🚀 Tech Stack

- **React** (Frontend framework)  
- **Tailwind CSS** (Utility-first styling)  

## 📦 Installation

1️⃣ Clone the repository:
```bash
git clone https://github.com/kunj1825/ToDo_List.git
cd ToDo_List
```

2️⃣ Install dependencies:
```bash
npm install
```

3️⃣ Run the app:
```bash
npm start
```
